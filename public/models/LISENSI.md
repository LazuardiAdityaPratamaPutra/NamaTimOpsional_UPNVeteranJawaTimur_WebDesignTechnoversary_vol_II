# Model 3D (CC0 1.0)

Model `.glb` di folder ini adalah karya pihak ketiga berlisensi CC0 1.0 (domain publik). Atribusi tidak wajib, tetapi kami mencantumkannya.

- Kenney (https://www.kenney.nl): Nature Kit (pohon, semak, batu, tenda), City Kit Commercial (bangunan), Car Kit (truk pemadam).
- Quaternius (https://quaternius.com): model tambahan di pustaka yang sama.

Berkas disalin dari paket npm `@netforge/asset-library-files` (MIT untuk seleksi dan optimasi; kompresi meshopt). Teks hukum CC0 ada di `CC0-1.0.txt`.
